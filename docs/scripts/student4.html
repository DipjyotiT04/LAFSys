"Compilation successful. Now let us run it."

"This is the main menu. Notice the live counters at the bottom — Lost, Found, Resolved. These update in real time."
Point at the terminal output showing the menu and counters.
"Let me post a lost item. I choose option 1."
Type 1 — Press Enter.
"I will enter — Phone as the name, Electronics as category, today's date, Library as the location, and a contact number."
Type each field one by one. Pause briefly after each Enter so audience can see.
"Saved. The system assigned it ID 16. Let us verify."

"Option 3 — View Lost Items."
Type 3 — Press Enter. The table appears.
"There it is. ID 16, Phone, Electronics, Library, today's date, status OPEN. The counter now shows Lost: 2."
Point at the new row in the table. Then point at the updated counter.
"Now let me search for it. Option 5 — Keyword search — type Phone."
Type 5, then 1, then Phone — Press Enter after each.
"One result found. The stream filtered all items and returned only the match."
Point at the search result in the terminal.
"Now the best part — claiming the item. Option 6."
Type 6 — Press Enter.
"Enter the item ID — 16. The system shows the item details and asks for confirmation."
Type 16 — Press Enter. Point at the item display.
"Mark resolved? Y."
Type y — Press Enter. "Done." appears.
"Done. The status changed from OPEN to RESOLVED. The file was rewritten."
Point at the "Done." message. Pause 1 second.
"Let me verify. View Resolved — option 7."
Type 7 — Press Enter.
"There it is. ID 16, Phone, status RESOLVED. The full cycle — Post, Save, Search, Claim — complete."
Point at the resolved item in the table. Make a circular motion to indicate "full cycle."
"Now let me show you the test results."

"23 tests. All passed. Zero failures."

Pause here — this is a strong moment. Let it sink in.
