Student 1 - Introduction, Problem & Objectives

Time: 2 minutes
"Good morning everyone. Today we are presenting LAFSys - a Campus Lost and Found System."
Action: Stand confident. Show title slide on screen.
"Let me start with a simple question - how many of you have lost something on campus?"
Action: Pause for 2 seconds. Look at audience.
"Every day, students lose wallets, phones, books, and ID cards. Finding them is difficult because there is no central system."
Action: Point to problem slide if available.
"Currently, people use social media, WhatsApp groups, or paper boards. These are scattered, not searchable, and items get lost forever."
Action: Count problems on fingers - scattered, not searchable, no tracking.
"Our problem is clear - there is no centralized, digital system for managing lost and found items on campus."
Action: Emphasize "centralized" and "digital".
"Our objectives are simple. First - let students post lost items. Second - let them post found items. Third - enable search by keyword and category. Fourth - allow claiming items when found."
Action: Count 4 objectives on fingers.
"The system is built in Java, uses a text file for storage, and runs in the console. Simple, effective, and portable."
Action: Show project structure slide if available.
"Now I will hand over to our next presenter who will explain the class design and Java concepts used."
Action: Gesture towards next presenter. Step back.
