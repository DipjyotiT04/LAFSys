# Campus Lost and Found Board

A Java Swing desktop application for managing lost and found items on campus.

## Features
- Post lost items and found items
- View all lost or found items
- Search items by keyword or category
- Claim items (mark as resolved)
- All records saved permanently in a plain text file

## Project Structure
```
lost-and-found-board/
  src/          - Java source files
  data/         - items.txt database
  docs/         - Bug log and report outline
  screenshots/  - Screenshot naming guide
```

## How to Run (Terminal)
```bash
# Compile
javac -d bin src/*.java

# Run
java -cp bin Main
```

## How to Run (IntelliJ / VS Code)
1. Open the `lost-and-found-board` folder
2. Open `src/Main.java`
3. Run the main method

## Tech Stack
- Java 8+
- Swing (built into JDK)
