Screenshot Naming Guide
======================

Save screenshots with these names:
  01-home-board.png        - Main window on startup
  02-post-lost-form.png    - Post Lost Item dialog
  03-post-found-form.png   - Post Found Item dialog
  04-view-lost.png         - Board showing lost items
  05-view-found.png        - Board showing found items
  06-search-results.png    - Search results displayed
  07-claim-dialog.png      - Claim confirmation dialog
  08-resolved-view.png     - Resolved items list
